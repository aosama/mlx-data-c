# Instructions for MLX-DATA-C Repo

- The intent of this code base is to provider C bindings that stay as true as possible to the https://github.com/ml-explore/mlx-data implementation.
- The final aim is to enable usage of mlx-data from Rust code.

## Before Commiting or Pushing You Must Do

- Do a self code review using the skill with the same name before commiting or pushing your changes.
- Keep readme.md updated with the latest changes after a careful and total review.
